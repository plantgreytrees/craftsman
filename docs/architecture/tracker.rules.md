# ARCH tracker — enforced rules

- **ARCH-TRACKER-01** [decided] The ledger stays the source of truth; .craftsman/runs/<slug>.json is a derived feature list regenerated on every transition and never hand-edited — check: run-manifest.test.mjs — cite: scripts/tracker.mjs:317-324, scripts/run-manifest.mjs:26-50
- **ARCH-TRACKER-02** [decided] Ledger events may gain fields but never lose them, and renderBlock output stays unchanged — check: tracker.test.mjs snapshot — cite: scripts/tracker.mjs:146-170,351-359
- **ARCH-TRACKER-03** [decided] A PARKED event from an autonomous run MUST carry decision {question, options[, recommended]}; Phase C is built from these — check: tracker.test.mjs — cite: scripts/tracker.mjs:54-86
- **ARCH-TRACKER-04** [decided] Autonomous runs MUST NOT emit CANCELLED; a unit reaches COMPLETE only through ticked [unit:] criteria — check: tracker refusal test — cite: scripts/tracker.mjs:64-101
- **ARCH-TRACKER-05** [decided] Each unit starts with a smoke run of the repo's gate command before editing — check: unit-runner.md step — cite: agents/unit-runner.md:14
- **ARCH-TRACKER-06** [decided] FEATURE_MERGED is a unit landed on its feature branch: it needs ticked [unit:] criteria like MERGED, is never auto-promoted, and reaches COMPLETE only through land-feature, which promotes every row of the feature with the landing sha — check: tracker.test.mjs transitions — cite: scripts/tracker.mjs:17-29,393
- **ARCH-TRACKER-07** [decided] Ledger events gain optional feature and feature_branch; the run manifest keeps features[] as units and adds feature_groups; no migration rewrites scope_id — check: run-manifest.test.mjs — cite: scripts/run-manifest.mjs:26-48
- **ARCH-TRACKER-08** [decided] A `[feature:<id>]` criterion gates its feature's land-feature; untagged criteria gate only the last feature's land-feature — check: core.test.mjs, tracker.test.mjs — cite: scripts/lib/core.mjs:514-519, scripts/repo-exec.mjs:571-584
- **ARCH-TRACKER-09** [decided] TRACKER-archive.md headings are machine-readable and tracker.mjs lookup {plan|slug} returns the parsed line — check: tracker.test.mjs lookup — cite: scripts/tracker.mjs:458-503
- **ARCH-TRACKER-10** [decided] Each epic and story has a generated docs/plans/<slug>/TRACKER.md rollup rendered from the ledger through plan-index (a parent is COMPLETE only when every descendant row is COMPLETE); it is fenced, pre-guard-protected and never hand-edited; the root TRACKER.md block and renderBlock stay unchanged — check: tracker.test.mjs rollup snapshot, pre-guard.test.mjs — cite: scripts/tracker.mjs:265-272, scripts/lib/tracker-rollup.mjs:1-115
- **ARCH-TRACKER-11** [decided] `tracker.mjs publish` is the only path that commits progress to base: under the base merge lock it renders the block, the rollups and docs/plans/TRACKER.jsonl into a detached temp worktree at origin/<base>, commits only those pathspecs, pushes HEAD:<base>, re-renders and retries once on rejection, and never parks a unit; it runs at feature prepare, on each unit landed (FEATURE_MERGED), parked or blocked, at feature landing and on /sync-docs --tracker, never per IN_PROGRESS — check: tracker-publish.test.mjs — cite: scripts/tracker-publish.mjs:72-134
- **ARCH-TRACKER-12** [superseded by ARCH-TRACKER-13]
- **ARCH-TRACKER-13** [decided] publish and sync MUST refuse any render that drops a committed row key (docs/plans/TRACKER.jsonl, else the committed TRACKER.md block's plan|unit pairs) without a tracker_archived or doc_retired event for that key since the last tracker_published, logging tracker_publish_refused {dropped[]}; `tracker.mjs init` rehydrates an absent local ledger from TRACKER.jsonl, and `init --merge` adds only keys absent locally and absent from TRACKER-archive.md headings — check: tracker-publish.test.mjs 50-vs-5, jsonl-absent and merge cases — cite: scripts/lib/ledger-keys.mjs:15-75
- **ARCH-TRACKER-14** [decided] A repo with a committed TRACKER.md block but no TRACKER.jsonl is repaired by `tracker.mjs init --from-block`: one row per block row (plan, unit, module, status), evidence "rehydrated from TRACKER.md block", never overwriting a key the local ledger holds; the next approved publish writes TRACKER.jsonl — check: tracker.test.mjs from-block case on a 50-row fixture — cite: scripts/tracker.mjs:236-268
- **ARCH-TRACKER-15** [decided] Whole-plan criteria carry `[plan:<slug>]` (tags in any order; `[unit:]` decides) and hold only that plan's promotion and land-feature; untagged lines hold none; headers never attribute — check: acceptance-plan-scope.test.mjs — cite: scripts/lib/core.mjs:506-518
- **ARCH-TRACKER-16** [decided] stop-gate binds an owning session to `[unit:X]`/`[plan:X]` lines only when its ledger names X; an untagged line binds only a session whose ledger names no plan (unreadable ledger = none, fail closed), else it goes in the Stop notice; the block reason names each line's plan — check: stop-gate-plan-scope.test.mjs — cite: scripts/stop-gate.mjs:340-358
