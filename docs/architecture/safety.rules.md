# ARCH safety — enforced rules

- **ARCH-SAFETY-01** [decided] Outside-root writes, deletes and credential reads MUST be left to the Claude Code sandbox; craftsman adds no guard for them — check: pre-guard.mjs names no outside-root write, delete or credential-read rule; /craftsman:init recommends the sandbox settings — cite: scripts/pre-guard.mjs:2-6
- **ARCH-SAFETY-02** [decided] A safety hook (pre-guard, agent-mode-guard, orchestrate-scope-guard) MUST fail closed: with node missing hooks/run.sh exits 2 with "node not found, guards cannot run", and any exit other than 0 or 2 from the hook itself is a denial too; the one exception is a UserPromptSubmit event, where exit 2 would erase the prompt, so it says the prompt was not checked and exits 0 — check: launcher.test.mjs — cite: hooks/run.sh:49-81
- **ARCH-SAFETY-03** [decided] A safety hook MUST also fail closed in process: bad JSON, empty stdin, an uncaught error or a failed context load exits 2 naming the guard; onFailure "block" in hooks.json (Claude Code 2.1.295+) is only a second layer — check: pre-guard.test, agent-mode-guard.test and orchestrate-scope-guard.test fail-closed cases — cite: scripts/pre-guard.mjs:21-36, scripts/agent-mode-guard.mjs:56-71, scripts/orchestrate-scope-guard.mjs:72-87
- **ARCH-SAFETY-04** [decided] Advisory hooks (quality-gate, stop-gate, builtin-skill-context) MAY fail open on bad input but MUST say so once per session, and SessionStart MUST report whether the guards are on or off and why — check: core.test.mjs advisory cases, session-context.test.mjs reason strings — cite: scripts/lib/core.mjs:625-649, scripts/session-context.mjs:34-48
- **ARCH-SAFETY-05** [decided] Only CRAFTSMAN_SAFETY=off in the user's environment MUST disable the safety hooks; CRAFTSMAN=off, .craftsman/off and enabled:false switch off the quality, doc and tracker machinery only, and a tool call cannot create .craftsman/off, a grant, marker, goal token or scope file (by write, mkdir, ln or a symlinked directory, judged by real path), edit hooks.json, the safety keys of the config or the hook-disabling keys of .claude/settings*.json, or run toggle.mjs off or doc-write.mjs on in any invocation outside a craftsman command (and scope activation honours a manifest naming hooks.json, the config or settings only after /orchestrate or /auto) — check: pre-guard.test.mjs self-disable table, core.test.mjs safetyEnabled — cite: scripts/lib/core.mjs:589-591, scripts/pre-guard.mjs:1016-1084, scripts/pre-guard.mjs:1110-1121, scripts/scope.mjs:149-154
- **ARCH-SAFETY-06** [decided] Stop and SessionEnd MUST report unpushed work in the main checkout and every worktree (uncommitted changes, stashes, branches ahead of or without an upstream, detached commits) from local refs only; Stop blocks on it only when stopGate.blockOnUnpushed is true — check: unpushed.test.mjs, stop-gate.test.mjs, session-end.test.mjs — cite: scripts/lib/unpushed.mjs:29-73, scripts/stop-gate.mjs:26-34, scripts/stop-gate.mjs:360-365, scripts/session-end.mjs:6-26
- **ARCH-SAFETY-07** [decided] The worktree sweep MUST be evidence-based and reversible: a branch counts as merged only into a remote-tracking base ref, a worktree holding non-disposable ignored files or living under .claude/worktrees (unless worktrees.sweepClaudeWorktrees) is kept, and every branch deletion is logged with its sha first — check: worktree-sweep.test.mjs — cite: scripts/worktree-sweep.mjs:46-52, scripts/worktree-sweep.mjs:173-184
- **ARCH-SAFETY-08** [decided] Safety MUST NOT depend on git anchoring: outside a git repository the protected-path, scope, dispatch and fail-closed checks stay on, and only the quality, doc and tracker machinery goes off, writing no state — check: pre-guard.test.mjs non-git cases, core.test.mjs safetyEnabled — cite: scripts/lib/core.mjs:589-598, scripts/pre-guard.mjs:806-810, scripts/lib/core.mjs:1007-1010
- **ARCH-SAFETY-09** [decided] The mod MUST submit a goal only if craftsman wrote it this session: /instruction and /auto record a token through scripts/goal-token.mjs (name and mtime, per session, minted only after one of those commands ran) and hooks/register.js launches only a goal file that matches one, otherwise it names the file and does not submit — check: register.test.ts, goal-token.test.mjs — cite: hooks/register.js:101-126, scripts/goal-token.mjs:15-38
- **ARCH-SAFETY-10** [decided] Post-hoc detection MUST report, never replace the guard: SessionStart records the hash of every guarded doc, Stop reports guarded docs that changed without a doc-guard edit allow (a Read does not count), and /craftsman:init only offers (diff first, nothing written without a yes) to merge sandbox settings — check: doc-snapshot.test.mjs, stop-gate.test.mjs, settings-merge.test.mjs, init.test.mjs — cite: scripts/lib/doc-snapshot.mjs:19-56, scripts/stop-gate.mjs:366-380, scripts/lib/settings-merge.mjs:38-52
- **ARCH-SAFETY-11** [decided] A filter in front of pre-guard MAY skip it only where it cannot act: hooks/run.sh skips node for Read, Glob and Grep only when no scope or scope-required file exists for the session, the call names nothing protected-looking, and no project config overrides protectedPaths; every other tool, and anything it cannot read, runs the guard — check: pre-guard.test.mjs parity table, launcher.test.mjs filter and timing cases — cite: hooks/run.sh:15-47, hooks/run.sh:54-63
