# Phase D — `--deep`: exhaustive whole-run audit

Triggered by `--deep <run-slug>`. The mandate is **completeness, not speed**: find *every* defect across the entire surface an orchestrate run produced. Scale the fan-out to the run; do not stop at the first plausible pass. Uses `${CLAUDE_PLUGIN_ROOT}/commands/_shared-analysis.md`'s bounded fan-out pattern, overriding its default cap (this phase's matrix caps at 12 modules, not ~15).

1. **Resolve the full surface (not a single diff).** From the run's execution rows: every unit, every merge SHA. Build the complete changed-file set (`git diff --name-only <merge-base>..main` per merged unit). Re-read the originating plan doc(s) — the promised user-visible outcomes are the yardstick. Recall memory per area.
2. **Mechanical floor across the whole surface** — run the full Phase-0 check set over *every* touched module + range, plus any completeness pre-filter over `<run-base>...HEAD`. Every hit seeds the inventory.
3. **Exhaustive multi-dimensional fan-out (parallel, read-only), capped.** Dispatch **one comprehensive reviewer per changed module**, briefed with its governing `docs/` reference and the complete defect-class checklist — correctness/logic · swallowed/mis-handled exceptions vs intended fail-closed · missing input validation · auth/permissions bypass · race/ordering · N+1 / missing pagination / perf · **stale contract between components** · dead/mis-set config/dangling flags · house-style conformance · simplification · reuse/duplication · **test-coverage gaps** on every new path · observability gaps. The reviewer must explicitly report each class as `FOUND`, `CLEAR`, or `UNPROVEN`; a class no reviewer is told to hunt is a class you miss. **The completeness hunt (#1 miss class)** is part of every module review: check what the plan did not mention — a contract consumer left un-updated, a path not wired, an endpoint unguarded, or a half-implementation. **Cap the fan-out at 12 reviewer calls per round**, selecting modules by changed-line count and logging dropped modules plus their reason. Dispatch specialist agents (`security-auditor`, `consumer-tracer`, `standards-keeper`, `idiom-reviewer`, `ui-ux-reviewer`, `migration-reviewer`, `api-reviewer`, `dependency-auditor`, `performance-reviewer`, or `observability-reviewer` — whichever fit the module) only for a surviving finding or an explicitly triggered high-sensitivity module. This preserves defect-class coverage without multiplying every class by every module. Unlike the default `/scrutinise` pass — which skips `standards-keeper`/`idiom-reviewer` because `/orchestrate` already ran them per-unit — `--deep` is exactly where those two lenses still earn their keep: checking consistency **across** units authored by separate implementer passes, something no single-unit review can see.
4. **Adversarial verification (every finding, no exceptions).** Trace the cited lines, try to **refute** first, record only survivors (sequential-thinking / context7 if available for the harder ones). An unverified "defect" is noise — discard it.
5. **Loop-until-dry, capped.** Re-fan-out only on findings rated Warning/Major or above (a Minor/Suggestion finding doesn't earn another round). Keep going until **two consecutive rounds find nothing new that clears that bar**, with a **hard ceiling of 4 rounds** regardless; log what each round added, and log it plainly if the cap — not dryness — is what stopped the loop.
6. **Emit + hand off.** Assemble **every verified finding in the conversation** (class, `file:line`, evidence, governing rule, severity, fix task), sequenced correctness → security → conformance → reuse/simplification → coverage, plus one execution row per module needing fixes with a `### Tooling` manifest — then **auto-delegate persistence to `/plan`** (SlashCommand) with the full audit; `/plan` persists `docs/plans/scrutinise-<run-slug>.md` and registers the rows. Record memory. Report: total findings by class + severity, rounds run until dry (or capped), modules dropped by the fan-out cap (if any), residual confidence (proven vs. couldn't-prove, e.g. runtime-only defects if nothing ran). Do **not** fix — next step **`/plan`**, then **`/orchestrate scrutinise-<run-slug>`**, then `/sync-docs`.
